Overview Quality Analytics Quarantine Pipeline

Reproducible pipeline

Fixed seeds, pinned logic, independent SQL validation, 95% test coverage with CI. Re-running produces identical outputs.

Run it

# full pipeline: generate → profile → clean → validate → report
python -m src.cli run-all --seed 42

# individual stages
python -m src.cli generate --rows 7500 --seed 42
python -m src.cli profile
python -m src.cli clean
python -m src.cli validate
python -m src.cli report

# interactive app
python -m streamlit run app.py

Stages

1 · Generate

src/generate_data.py — Faker + seeded RNG, ~7,500 rows with 12 documented defect classes.

2 · Profile

src/profiling.py — nulls, duplicate business keys, top values snapshot.

3 · Clean

src/cleaning.py — standardization, business rules, quarantine tagging.

4 · Validate

src/validation.py + sql/ — DuckDB quality checks & analytics.

5 · Report

src/reporting.py — Markdown, JSON, and summary CSV outputs.

6 · Serve

app.py — Streamlit dashboard mirroring every stage. This static site is built from its outputs.
